### Architecture Issues

| # | Issue | Severity | Impact |
|---|-------|----------|--------|
| 1 | Monolithic frontend | HIGH | No code splitting, slow loads |
| 2 | Mixed module systems | HIGH | IIFE + ES Modules = complexity |
| 3 | No dependency injection | MEDIUM | Tight coupling |
| 4 | In-memory state | HIGH | Lost on cold start |
| 5 | No event-driven architecture | MEDIUM | Tight coupling |
| 6 | No proper error boundaries | HIGH | Silent failures |
| 7 | No proper logging | MEDIUM | Hard to debug |
| 8 | No proper caching | MEDIUM | Repeated work |

### Key Improvements Needed

1. **Migrate to Firebase Auth** — Replace custom JWT with Firebase Auth
2. **Add Redis/Upstash** — For rate limiting and caching
3. **Implement Code Splitting** — Dynamic imports for admin pages
4. **Add Error Boundaries** — React error boundaries or equivalent
5. **Implement Event System** — Decouple modules with events
6. **Add Proper Logging** — Sentry for errors, Datadog for metrics
7. **Add Type Safety** — TypeScript or JSDoc types
8. **Implement CQRS** — Separate read/write models
